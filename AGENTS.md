# AGENTS.md

## Directiva de idioma (OBLIGATORIA)

**Idioma de todas las respuestas: ESPAÑOL.**

- Todas las respuestas, explicaciones, comentarios de código, mensajes de commit,
  documentación y resúmenes generados por cualquier IA que trabaje en este
  repositorio DEBEN estar escritos en español.
- Esto aplica a: esta herramienta (opencode / Claude Code / Cursor / Google Antigravity
  IDE / GitHub Copilot / cualquier asistente) y a cualquier agente o skill que opere aquí.
- Si una herramienta viene configurada por defecto en otro idioma, se debe indicar en
  su configuración o prompt que utilice español de forma permanente.
- Se permite el inglés únicamente para: nombres de variables, clases, funciones,
  identificadores, claves de array y textos literales del código fuente.
